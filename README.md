# Vishu

A local-first personal AI agent that **does your work** and **builds software** — a
Claude-Code-style engine that runs standalone in the terminal first, then gets a UI on top.
Token-frugal, provider-agnostic with automatic failover, reliable via self-verification, with
an Obsidian-style memory vault, a shared SKILL.md library, proactive automation, and a guided
secure app builder.
